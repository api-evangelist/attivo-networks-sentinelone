# Attivo Networks (SentinelOne)

> Attivo Networks was a pioneer in identity threat detection and response (ITDR), deception, and Active Directory attack protection. It was acquired by SentinelOne in 2022 and its technology is now delivered as SentinelOne Singularity Identity within the AI-powered Singularity security platform. This API Evangelist profile tracks the security, trust, and disclosure surface for the combined entity; there is no standalone public Attivo API — programmatic access is provided through the SentinelOne management console REST API.
